D CONVENTION — WEBSITE CONCEPT DEMO

How to run:
1. Extract this ZIP.
2. Open the extracted d-convention-demo folder in VS Code.
3. Right-click index.html and choose Open with Live Server.

Files:
- index.html, about.html, facilities.html, gallery.html, contact.html
- style.css, script.js
- images/: bundled SVG fallbacks used automatically if the external listing images do not load

Photo note:
The page uses image URLs listed on the Mandap.com D Convention Hall 2 venue page at the same Kakinada address. The site includes bundled local SVG fallbacks so a blocked image does not display a broken-image icon. Obtain the venue's permission and use owner-approved original photos before making a commercial website live.

Demo limitations:
- WhatsApp enquiry opens a pre-filled message; it does not store bookings.
- Google Maps embed requires internet.
- Google Fonts require internet, with standard fallback fonts available.
- This is a visual concept, not a confirmed official site.
